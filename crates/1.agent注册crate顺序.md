## 落地状态（2026-11）

上述 crates 已通过 `apps/qe-agent/src/boot/` 的引导流水线组织起来，
见 `docs/boot-pipeline.md`。对照：

| 流水线阶段  | 接入的 crate                                    | 状态 |
|------------|--------------------------------------------------|------|
| firewall   | qe-nftables（新建，nft 命令后端 + json-backend 预留） | ✅  |
| display    | apps/boot-display（Tauri 全屏展示层，agent spawn + supervise） | ✅ |
| checks     | platform-health + qeaudit + platform-diagnose（首次必检，周期复检） | ✅ |
| enroll     | qe-device-pki-client（配置不足→skipped，失败→failed，均不阻塞） | ✅ |
| services   | virt-crate（KVM 探测）+ qe-container + qep2p（检测与就绪标记） | ✅ |
| （长驻）    | qe-agent-node / qe-agent-telemetry 原路径不变，流水线只做检测 | ✅ |

IPC：`GET /v1/state` 全程可查；`POST /v1/checks-interval` 应用远端间隔；
远端 `config.update` 下发成功后经 `on_remote_policy_applied` 钩子自动联动
本机复检节奏（取 `telemetry_full_interval_secs`）。
